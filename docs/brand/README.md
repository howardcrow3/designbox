# DesignBox brand

The High Turtle logo as single-ink SVGs. Each file carries one fixed ink.

- Files without a suffix are filled with ink (`#17181a`), for light surfaces.
- Files ending in `-reversed` are filled with `#f6f6f5`, for dark surfaces.
- `logo-horizontal` is the default lockup (README, headers). `logo-stacked` suits square or tall
  spaces. `mark` is the turtle alone, for a favicon or avatar (and the source of the app icon).
  `wordmark` is the name alone and has no reversed version.

Do not stretch, recolor, outline or redraw the logo, and keep clear space around it equal to the cap
height of the name. These are the project owner's brand assets; see
[`assets/app-icon/LICENSE.txt`](../../assets/app-icon/LICENSE.txt) and [`ATTRIBUTION.md`](../../ATTRIBUTION.md)
for their terms.
